**令牌桶**（Token Bucket）是一种常见的流量控制算法，用于限制数据流量的传输速率，保证系统资源的合理分配和利用。它广泛应用于网络流量控制、带宽管理和流量整形。

---

### **基本原理**
1. **令牌生成**：
   - 系统以固定速率生成令牌，令牌存储在一个容量有限的桶中。
   - 如果桶满了，新增的令牌会被丢弃。

2. **数据传输**：
   - 每次需要发送数据时，必须从桶中取出一定数量的令牌。
   - 如果桶中有足够的令牌，允许发送；否则，传输请求被限制或延迟。

3. **令牌消耗**：
   - 每个数据包根据其大小或其他规则消耗相应数量的令牌。
   - 只有令牌足够时才能发送，否则数据流被抑制。

---

### **关键参数**
- **桶容量**（`B`）：桶中最多能存放的令牌数，用来限制短时间内可以发送的最大数据量。
- **令牌生成速率**（`r`）：令牌生成的速度，用来限制长期的数据传输速率。
- **令牌消耗量**：每个数据包需要消耗的令牌数，通常与数据包的大小成正比。

---

### **工作示例**
假设：
- 令牌生成速率为 10 个令牌/秒。
- 桶容量为 100 个令牌。
- 每 1 字节的数据需要消耗 1 个令牌。

工作流程：
1. 如果数据传输速率低于 10 字节/秒，桶中的令牌会逐渐增加。
2. 如果数据传输速率高于 10 字节/秒，但低于 100 字节/秒，可以暂时使用积累的令牌满足传输需求。
3. 如果速率持续高于 100 字节/秒，桶会被耗尽，多余的数据将被丢弃或限速。

---

### **令牌桶的优点**
1. **平滑突发流量**：允许突发流量在短时间内使用积累的令牌，但不能超过桶容量。
2. **灵活控制速率**：通过调整令牌生成速率和桶容量，可灵活设置速率和突发流量的限制。
3. **简单易实现**：令牌桶算法实现逻辑简单，适合硬件和软件实现。

---

### **令牌桶 vs 漏桶**
| **特点**         | **令牌桶**                               | **漏桶**                               |
|-------------------|------------------------------------------|----------------------------------------|
| **控制方式**      | 限制流入速率，允许突发流量。               | 限制流出速率，抑制突发流量。           |
| **突发能力**      | 支持突发流量，受桶容量限制。               | 不支持突发流量，流量始终以固定速率输出。 |
| **实现复杂度**    | 相对灵活，更适合动态流量场景。             | 实现简单，适合严格流量整形的场景。     |

---

### **令牌桶的典型应用**
1. **网络流量整形**：
   - 限制流量速率，防止网络拥塞。
   - 控制突发流量，提高传输性能。
   
2. **API 请求限流**：
   - 在分布式系统中，用于限制用户的请求频率。
   - 防止服务器因高并发请求而过载。
   
3. **带宽管理**：
   - 控制各类服务的最大带宽使用量，防止某些服务占用过多资源。

### **实现代码示例（伪代码）**
```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

typedef struct {
    int tokens;         // 当前令牌数
    int bucket_size;    // 桶容量
    int token_rate;     // 令牌生成速率（令牌/秒）
    time_t last_time;   // 上次生成令牌的时间
} TokenBucket;

void init_bucket(TokenBucket *bucket, int size, int rate) {
    bucket->tokens = 0;
    bucket->bucket_size = size;
    bucket->token_rate = rate;
    bucket->last_time = time(NULL);
}

void add_tokens(TokenBucket *bucket) {
    time_t now = time(NULL);
    int new_tokens = (now - bucket->last_time) * bucket->token_rate;
    bucket->tokens += new_tokens;
    if (bucket->tokens > bucket->bucket_size) {
        bucket->tokens = bucket->bucket_size;
    }
    bucket->last_time = now;
}

int consume_tokens(TokenBucket *bucket, int amount) {
    add_tokens(bucket);
    if (bucket->tokens >= amount) {
        bucket->tokens -= amount;
        return 1; // 允许发送
    } else {
        return 0; // 不允许发送
    }
}

int main() {
    TokenBucket bucket;
    init_bucket(&bucket, 10, 5); // 桶容量10，生成速率5令牌/秒

    while (1) {
        if (consume_tokens(&bucket, 3)) {
            printf("发送数据包\n");
        } else {
            printf("流量受限\n");
        }
        sleep(1);
    }
    return 0;
}
```

---

### **总结**
令牌桶是一种灵活、高效的流量控制算法，适合需要支持突发流量的场景。通过合理设置桶容量和令牌生成速率，可以实现对系统资源的高效利用，同时防止过载。
