在 Linux 中，`alarm()` 只能提供秒级的定时精度。如果需要更精确的计时器，可以使用以下方式：  

---

### **1. `setitimer()`（微秒级定时器）**
`setitimer()` 提供了微秒级（us，1,000,000 分之一秒）的定时器。可以设置定时器发送 `SIGALRM` 信号，适用于周期性或一次性定时任务。  
**示例：**
```c
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>
#include <sys/time.h>
#include <unistd.h>

void timer_handler(int signum) {
    printf("Timer expired!\n");
}

int main() {
    struct itimerval timer;
    
    signal(SIGALRM, timer_handler);  // 设置信号处理函数

    timer.it_value.tv_sec = 1;       // 1 秒后触发
    timer.it_value.tv_usec = 500000; // 额外 500 毫秒
    timer.it_interval.tv_sec = 0;    // 只触发一次
    timer.it_interval.tv_usec = 0;   

    setitimer(ITIMER_REAL, &timer, NULL);

    while (1); // 保持程序运行
}
```
**精度**：微秒级（`us`），但受系统调度影响，实际可能略有偏差。

---

### **2. `timer_create()` + `timer_settime()`（纳秒级，POSIX 定时器）**
`timer_create()` 使用 `clock_gettime()` 的时钟源，如 `CLOCK_REALTIME` 或 `CLOCK_MONOTONIC`，提供纳秒级（ns，10 亿分之一秒）定时精度。

**示例：**
```c
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>
#include <time.h>
#include <unistd.h>

void timer_handler(union sigval sv) {
    printf("Timer expired!\n");
}

int main() {
    struct sigevent sev;
    struct itimerspec its;
    timer_t timerid;

    sev.sigev_notify = SIGEV_THREAD; // 触发时创建新线程
    sev.sigev_notify_function = timer_handler;
    sev.sigev_value.sival_ptr = &timerid;

    timer_create(CLOCK_REALTIME, &sev, &timerid);

    its.it_value.tv_sec = 0;
    its.it_value.tv_nsec = 500000000; // 500 毫秒
    its.it_interval.tv_sec = 0;
    its.it_interval.tv_nsec = 0; // 只触发一次

    timer_settime(timerid, 0, &its, NULL);

    sleep(2); // 等待定时器触发
    return 0;
}
```
**精度**：纳秒级（`ns`），适用于高精度定时任务，但仍受系统调度影响。

---

### **3. `clock_nanosleep()`（高精度睡眠）**
如果只是需要高精度延时，而不是定时触发信号，可以使用 `clock_nanosleep()`，它支持纳秒级休眠。

**示例：**
```c
#include <stdio.h>
#include <time.h>

int main() {
    struct timespec ts;
    ts.tv_sec = 0;
    ts.tv_nsec = 500000000; // 500 毫秒

    printf("Sleeping...\n");
    clock_nanosleep(CLOCK_MONOTONIC, 0, &ts, NULL);
    printf("Woke up!\n");

    return 0;
}
```
**精度**：纳秒级，适用于精确控制延迟的场景，如实时系统。

---

### **4. `eventfd()` + `epoll()`（更适用于高性能定时任务）**
对于多线程或高性能 IO 场景，结合 `eventfd()`、`epoll()` 和 `timerfd_create()` 使用可减少信号干扰，提高效率。

---

### **总结**
| 方法               | 精度       | 适用场景 |
|--------------------|-----------|---------|
| `alarm()`          | 秒级       | 简单定时任务 |
| `setitimer()`      | 微秒级     | 低精度周期定时 |
| `timer_create()`   | 纳秒级     | 高精度定时，POSIX |
| `clock_nanosleep()`| 纳秒级    | 高精度休眠 |
| `eventfd()` + `epoll()` | 纳秒级 | 高性能 IO 定时 |

如果需要更精确的计时，推荐使用 `timer_create()` 或 `clock_nanosleep()`。
